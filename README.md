# gpolkcard

Digital business card for Aaron Dobrow, Glenn Polk Auto Group.

Live at https://gpolk.thedobrowgroup.com

Static site, no build step. Deployed from this repo via Vercel.

## Files

- `index.html` — the card page
- `contact.vcf` — vCard, downloaded by the Save contact button
- `logo.png` — logo, transparent background
- `logo-dark.png` — brightened variant for dark mode
- `vercel.json` — serves the .vcf with the correct content type
